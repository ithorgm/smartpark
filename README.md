# SmartPark 🚗

**SmartPark** es un sistema de gestión de estacionamientos diseñado para facilitar la administración de vehículos y la asignación de espacios de estacionamiento. Este proyecto está desarrollado con tecnologías modernas como **HTML5**, **CSS**, **Bootstrap** y **JavaScript**.




## Características principales
- Registro y gestión de usuarios.
- Asignación de espacios de estacionamiento.
- Interfaz intuitiva y responsive gracias a Bootstrap.
- Fácil de usar y personalizar.
